# RepoDoctor — LovHack Season 3

AI repository health diagnosis: Scan → Diagnose → Evidence → Prescription → Fix → Rescan.

Includes explainable scoring, security/testing/docs/config/dependency/architecture signals, file evidence, AI prescriptions, repository X-Ray, scan modes, local scan history, Markdown export, sample report and contextual AI Quick Help.

Deploy the folder to GitHub/Vercel and set `OPENROUTER_API_KEY` in Vercel Environment Variables. Keep API keys server-side; never put them in frontend JavaScript.
